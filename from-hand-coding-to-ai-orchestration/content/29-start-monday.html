A starting point for Monday

  1. Write a short AGENTS.md and provide one command that runs the required checks
  2. Point your agent tools to that same file
  3. Add skills for commit and create-pr
  4. Put detailed rules in separate files that say when to read them
  5. Record decisions and caveats the next contributor will need
  6. Test whether agents follow the skills

You can stop after the first step and still have something useful. Keep the required checks as you add more.
