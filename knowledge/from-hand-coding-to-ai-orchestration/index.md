# From-hand-coding-to-ai-orchestration
* [Insert slides with suffixed names and keep order in SLIDES.md; displayed numbers drift from file numbers](slide-order-and-insertions.md) - New slides added between existing ones are named with a letter suffix on the preceding number (08b, 29b) instead of renumbering later files, because SLIDES.md owns the order and renaming churns every file; displayed slide numbers therefore no longer match file prefixes, and the README slide count is maintained by hand.
* [The LLMoxie slide is background that leads into the demo project, not a platform tour](llmoxie-background-slide.md) - The slide before the llmoxie-analysis demo introduction shows the LLMoxie architecture diagram but frames it as where the demo data comes from (collect through the gateway, accumulate from the team and workshops, analyze with a new library), so the audience arrives at the demo knowing why the data exists.
* [Closing sequence: Monday ladder, orchestra metaphor, shared-source callback, thank-you with partner logos](closing-sequence.md) - The deck ends with the adoption ladder, an orchestra slide mapping repo parts to sheet music (worded as repeatable, not deterministic), the callback to the shared-source diagram with an empty Your repo hub, and a thank-you slide with a looping uwssec.org partner logo video; the backup horror-stories slide was removed and filling the hub with the six parts was rejected as a repeat of the ladder.
* [Trial-run model names on the models-matter chart](trial-run-model-names.md) - The models-matter chart lists MAI Code 1.1 Flash (Microsoft AI), which an earlier draft misnamed MyCode; the label is a bare model name like the other bars, with no vendor suffix, and the same name appears in the NOTES.md row. The Qwen 3.8 bar was removed.
* [Deck-level presenter controls live in shared/footer.html: walkthrough keys, progress bar, full-screen toggle](presenter-controls.md) - The footer owns the deck controls for this deck: one walkthrough controller per slide driven by both the buttons and the Up and Down arrows, a fixed progress bar that replaces the static teal accent bar on screen only, and a full-screen handler for any element marked data-fullscreen, of which the title slide's translucent icon is the only instance.
