# Knowledge Base

Project memory for **presentations** — the Reveal.js decks and uw-slides decks
in this repository, and the GitHub Actions pipeline that renders each deck to
PDF and publishes it to Zenodo under the uw-ssec community.

This bundle records what the repository cannot tell you on its own: why a deck
or the pipeline is shaped the way it is, decisions and rejected alternatives,
and the constraints a change must keep. Setup, commands, and contribution rules
are not repeated here — they live in `AGENTS.md` and `README.md`.

This bundle is public. It never contains private, sensitive, or personally
identifiable information: no names, contact details, identifiers, credentials,
private communications, or unpublished data. People are referred to by role.
Requests to record such content are rejected or redacted before any write.

Read and write this bundle through the `okf` CLI, run as `pixi run okf`, or
through the `presentations` MCP server declared in `.mcp.json`. Start with
`okf search "<keywords>"` rather than browsing these files.

## Areas

Areas are added as concepts are recorded; each gets a folder with an
`index.md` listing its concepts.
