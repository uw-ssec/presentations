## Brand Compliance

All designs comply with [UW Brand Guidelines](https://www.washington.edu/brand/):

- Colors use official UW primary palette (purples + golds)
- Accent colors (teal, green, pink) limited to 15% coverage
- Typography uses Encode Sans (display), Open Sans (body), Encode Sans Compressed (UI)
- Logo usage follows UW restrictions (approved colors only, clear space rules)
- 15-degree angle motif incorporated from UW Boundless graphic elements
- WCAG 2.2 AA contrast verified for all text/background combinations

## SSEC Identity

What makes this distinctly SSEC (not generic UW):

- **Teal accent** (`#2ad2c9`) as the AI/tech signature color
- **Dark purple sections** with code/terminal aesthetics
- **JetBrains Mono** as the code font for technical credibility
- **Data stream animations** suggesting computation and AI
- **Node network visualizations** in hero sections
- **15-degree angled section dividers** as a structural signature
